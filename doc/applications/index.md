# Applications

model rocketry.

The application code lives in the top-level directories of the
[`aurora`](https://github.com/AUXSPACEeV/aurora) repository, e.g.
[`sensor_board`](https://github.com/AUXSPACEeV/aurora/tree/main/sensor_board).
